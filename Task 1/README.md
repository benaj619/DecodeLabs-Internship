# Task 1: Data Cleaning & Exploratory Data Analysis (Python)

## Overview
This task focuses on using Python to clean, structure, and inspect raw dataset records to ensure data integrity before conducting further analysis.

## Key Objectives
- Identify and handle missing, duplicate, or inconsistent records using Pandas.
- Standardize data formats across date fields, categorical values, and numeric measurements.
- Perform initial exploratory data analysis (EDA) and compute summary statistics programmatically.

## Files Included
- `Final.python.ipynb`: Jupyter notebook containing the Python code for data cleaning and EDA.
- `cleaned_dataset.xlsx`: The sanitized, fully formatted dataset exported after processing.
- `exported_data.xlsx`: Exported statistical summaries and data outputs.
